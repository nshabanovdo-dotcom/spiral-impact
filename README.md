# Spiral Impact

Прототип браузерной игры: летающие морды дерутся оружием на цепи (физика раскрутки, урон от скорости удара).

Запуск: открыть `index.html` в браузере. Режимы: тренировка, груша, дуэль 1×1, команды 4×4 против ботов и «Нашествие» — волны монстров.

## Что где лежит
- `index.html` — игра; картинки грузятся из `art/` (открывать через сервер, например GitHub Pages).
- `tools/build_single.py` — собрать игру в один HTML-файл со всеми картинками внутри.
- `armory.js` — склад оружия, прогресс, достижения, груша, выбивание оружия.
- `horde.js` — режим «Нашествие».
- `art/` — картинки морд: готовые головы и исходники (см. `art/README.md`).
- `tools/make_heads.py` — скрипт вырезки голов из картинок.
- `CHANGELOG.md` — история версий.
